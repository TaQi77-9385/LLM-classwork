# 贪吃蛇小游戏

纯前端实现，单个 HTML 文件，无需安装任何依赖。

## 运行方式

- **直接打开**：双击 `index.html`，用浏览器打开即可开始玩。
- **本地服务器**（可选）：
  ```bash
  cd snake-game
  python -m http.server 8000
  ```
  然后访问 http://localhost:8000

## 操作说明

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 转向 | 方向键 或 WASD | 在棋盘上滑动 / 点方向键 |
| 暂停 / 继续 | 空格 | 点按钮 |
| 重新开始 | 回车 | 点按钮 |

## 玩法与规则

- 20 × 20 网格，初始长度 3 格，吃到食物加 **10 分**。
- 每吃一个食物，速度加快，最低间隔 60ms。
- 撞墙或撞到自己（尾巴格除外）游戏结束。
- 不允许 180° 直接掉头，避免瞬间自杀。
- 最高分保存在浏览器 `localStorage` 中，刷新不会丢失。
- 切换窗口 / 浏览器失焦时自动暂停。

## 实现要点

- `requestAnimationFrame` + 时间累加器（accumulator）驱动固定步长逻辑，帧率不同速度也不变。
- Canvas 按 `devicePixelRatio` 缩放，高分屏不发虚。
- 蛇头有光晕和朝向眼睛，食物有呼吸光晕，吃到时全屏微闪反馈。
- 响应式：窄屏自动隐藏文字提示、显示虚拟方向键，棋盘尺寸自适应窗口。

## 可调参数

位于 `index.html` 脚本开头的「基础配置」区：

```js
const COLS = 20;         // 横向格数
const ROWS = 20;         // 纵向格数
const BASE_SPEED = 140;  // 初始速度（每步毫秒数，越小越快）
const MIN_SPEED = 60;    // 最快速度上限
const SPEED_STEP = 6;    // 每吃一个加速的毫秒数
```
