# 关于2026年国庆节放假安排的通知

各部门、全体员工：

根据《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号）精神，结合我单位实际情况，现将2026年国庆节放假有关事项通知如下：

## 一、放假时间

2026年10月1日（星期四）至10月7日（星期三）放假调休，共7天。

- 10月8日（星期四）起恢复正常工作；
- 9月20日（星期日）、10月10日（星期六）正常上班。

因9月25日至27日为中秋节假期，国庆与中秋两节相近，请各部门统筹安排好前后两个假期的工作衔接。

## 二、工作要求

1. **做好工作安排**：各部门须于放假前完成本阶段工作任务的梳理与交接，明确节假日期间的应急联系人及联系电话，确保工作不断档。
2. **加强安全管理**：放假前请各部门检查办公区域水、电、门窗，关闭非必要用电设备，妥善保管重要文件及贵重物品，做好防火、防盗等安全检查。
3. **严格值班制度**：值班人员须按时到岗，保持通讯畅通，遇突发事件或紧急情况，第一时间向分管领导报告并妥善处置。
4. **注意出行安全**：假期出行请合理安排行程，注意交通安全与人身财产安全，遵守目的地相关规定。国庆期间客流集中，建议错峰出行。

## 三、假期提示

请全体员工合理规划假期时间，注意劳逸结合，节后按时返岗。因故不能按时返岗的，须提前按程序办理请假手续。
