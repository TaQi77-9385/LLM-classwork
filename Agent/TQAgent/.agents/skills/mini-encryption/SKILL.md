# mini-encryption 技能（miniEncryption）

## 触发条件

当用户的消息中出现"加密保存"时，加载并使用本技能。

## 功能

将文本中所有阿拉伯数字**逐位**替换成中文数字，其余字符（汉字、字母、标点、空格、换行等）保持不变。

## 替换对照表

| 阿拉伯数字 | 中文数字 |
| --- | --- |
| 0 | 零 |
| 1 | 一 |
| 2 | 二 |
| 3 | 三 |
| 4 | 四 |
| 5 | 五 |
| 6 | 六 |
| 7 | 七 |
| 8 | 八 |
| 9 | 九 |

## 执行规则

1. 逐字符扫描文本，遇到阿拉伯数字 0–9 就按上表替换为对应中文数字。
2. 严格按位替换，不做数值读法转换：
   - `2024` → `二零二四`（不是"二千零二十四"）
   - `3.14` → `三点一四`
   - `10:30` → `一零:三零`
   - `138-0013` → `一三八-零零一三`
3. 非数字字符一律原样保留，不增删、不改动。
4. 全角数字（如 `１２３`）同样视为数字，先归一为半角再替换；若无法归一，则按字符原样保留并提示用户。
5. 替换完成后，把结果作为"加密后"的文本输出给用户。

## 输出格式

- 先说明已执行加密。
- 给出加密后的完整文本（放在代码块中，便于原样复制保存）。
- 若用户同时要求保存到文件，则在当前目录创建对应文件并写入加密后的文本。

## 示例

用户输入：

```
加密保存：订单号 2024-0917，数量 15 件。
```

输出：

```
已按 mini-encryption 技能加密（数字逐位转中文）：

订单号 二零二四-零九一七，数量 一五 件。
```
